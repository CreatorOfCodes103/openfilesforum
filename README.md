# OpenFiles Forum

A public file-sharing forum starter using HTML, CSS, JavaScript, Netlify Functions and Netlify Blobs.

## Deploy
1. Upload the contents of this folder to a GitHub repository.
2. In Netlify, choose **Add new project → Import an existing project** and connect the repository.
3. Use the settings in `netlify.toml`; no build command is needed.
4. Enable/provision Netlify Blobs if prompted, then deploy again if needed.
5. Open the published `*.netlify.app` URL and test using a small, non-sensitive file.

## Important
- 5 MB maximum per upload.
- Server and browser block `.iso`, `.img`, executables, scripts, and formats outside the allowlist.
- Uploaded files are public. Never upload private or confidential information.
- This starter does not yet include accounts, moderation, malware scanning, rate limits, or abuse reporting. Add those before advertising it broadly. Extension checks alone cannot prove a file is safe.
- SVG files are served as attachments, not rendered inline.
